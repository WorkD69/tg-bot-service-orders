# Руководство для владельца бизнеса

Это пошаговая инструкция для запуска Telegram-бота на вашем компьютере. Знание программирования не требуется.

---

## Что делает этот бот

Бот автоматизирует работу с клиентами в Telegram: клиент оставляет заявку, свободные операторы предлагают свою цену, вы или администратор выбираете подходящего исполнителя, клиент оплачивает — оператор выполняет работу и отправляет результат прямо в чат. Вы видите всю статистику и управляете настройками.

**Подходит для:** копирайтинг, дизайн, юридические услуги, IT-поддержка, курьерская доставка, ремонт — любой сервис, где клиент подаёт заявку, а исполнитель её берёт.

---

## Роли в системе

| Роль | Кто это | Что может делать |
|------|---------|-----------------|
| **Клиент** | Любой пользователь Telegram | Создаёт заявку, прикладывает файлы, общается с оператором, подтверждает оплату, оставляет отзыв |
| **Оператор** | Ваш сотрудник / фрилансер | Видит новые заявки в специальной группе, называет свою цену, берёт заявку в работу, загружает результат |
| **Администратор** | Ваш менеджер | Назначает роли, подтверждает оплаты вручную, видит статистику, контролирует выплаты |
| **Владелец** | Вы | Настраивает все параметры бизнеса прямо в Telegram, без изменения кода |

## Что нужно установить

### 1. Docker Desktop

Docker запускает все компоненты бота одной командой — вам не нужно ничего настраивать вручную.

1. Перейдите на сайт **docker.com/products/docker-desktop** и скачайте версию для вашей системы (Windows или Mac).
2. Установите и запустите. После запуска в правом нижнем углу появится значок Docker.
3. Проверьте, что всё работает: откройте **Командную строку** (Windows: нажмите Win + R, введите `cmd`, нажмите Enter) и введите:
   ```
   docker --version
   ```
   Вы должны увидеть что-то вроде: `Docker version 25.0.3`

### 2. ngrok

ngrok создаёт временный интернет-адрес для вашего компьютера, чтобы Telegram мог отправлять сообщения боту.

1. Перейдите на **ngrok.com**, зарегистрируйтесь (бесплатно).
2. Скачайте ngrok для вашей системы и распакуйте.
3. В личном кабинете ngrok скопируйте команду авторизации (выглядит как `ngrok config add-authtoken ВАШ_ТОКЕН`). Выполните её в командной строке.

### 3. Telegram

Приложение Telegram уже должно быть у вас. Убедитесь, что вы вошли в аккаунт.

---

## Шаг 1. Создайте бота через BotFather

BotFather — официальный бот Telegram для создания новых ботов.

1. Откройте Telegram и найдите **@BotFather** (синяя галочка рядом с именем — значит официальный).
2. Напишите ему `/newbot`.
3. Введите **имя бота** — это отображаемое название, например: `Мой Сервис`.
4. Введите **username бота** — латинские буквы, должен заканчиваться на `bot`, например: `myservice_orders_bot`.
5. BotFather пришлёт вам **токен** — длинную строку вида `1234567890:AAF...xyz`.

> Сохраните токен! Это ключ от вашего бота. Никому не передавайте.

---

## Шаг 2. Узнайте свой Telegram ID

Telegram ID — числовой идентификатор вашего аккаунта. Нужен для назначения вас владельцем бота.

1. Найдите в Telegram бот **@userinfobot**.
2. Напишите ему `/start`.
3. Бот пришлёт ваш ID — число вида `123456789`.

> Запишите это число — оно понадобится дважды: как ID администратора и как ID владельца.

---

## Шаг 3. Создайте группу операторов

В этой группе операторы будут видеть новые заявки от клиентов.

1. В Telegram создайте новую группу (кнопка "Написать" → "Новая группа").
2. Назовите её, например: `Операторы — Мой Сервис`.
3. Добавьте в группу созданного бота (по его username, например `@myservice_orders_bot`).
4. Назначьте бота **администратором** группы (зайдите в настройки группы → Администраторы → Добавить → выберите бота → дайте права на отправку сообщений).
5. Узнайте ID группы: добавьте в группу бот **@getmyid_bot** или **@RawDataBot**, напишите любое сообщение — бот пришлёт ID группы. ID группы всегда начинается с `-100`, например: `-1001234567890`.

> Запишите ID группы — он понадобится в настройках.

---

## Шаг 4. Скопируйте и заполните файл .env

Файл `.env` — это конфигурация бота с вашими данными.

### Как скопировать

**Windows (Командная строка):**
```
copy .env.example .env
```

**Windows (PowerShell):**
```
Copy-Item .env.example .env
```

**Mac / Linux:**
```
cp .env.example .env
```

### Что заполнить

Откройте файл `.env` в любом текстовом редакторе (Блокнот, Notepad++, VS Code) и замените значения:

| Поле | Что вставить | Пример |
|------|-------------|--------|
| `BOT_TOKEN` | Токен от BotFather | `1234567890:AAF...xyz` |
| `WEBHOOK_BASE_URL` | Пока оставьте как есть, заполним на шаге 6 | — |
| `WEBHOOK_PATH` | Не меняйте | `/telegram/webhook` |
| `WEBHOOK_SECRET` | Придумайте любой пароль из букв и цифр | `mysecret42abc` |
| `ADMIN_TELEGRAM_ID` | Ваш Telegram ID из шага 2 | `123456789` |
| `OWNER_TELEGRAM_ID` | Ваш Telegram ID из шага 2 | `123456789` |
| `OPERATOR_GROUP_ID` | ID группы операторов из шага 3 | `-1001234567890` |
| `POSTGRES_PASSWORD` | Придумайте пароль для базы данных | `mydbpassword123` |
| `DATABASE_URL` | Замените слово `replace_with_local_database_password` на тот же пароль | `postgresql+asyncpg://botuser:mydbpassword123@db:5432/botdb` |

> Строки `REDIS_URL`, `POSTGRES_USER`, `POSTGRES_DB` — не меняйте.

> **Robokassa** — платёжная система. Для демонстрационного режима оставьте поля `ROBOKASSA_LOGIN`, `ROBOKASSA_PASS1`, `ROBOKASSA_PASS2` **пустыми**. В этом режиме клиент сообщает об оплате, а администратор подтверждает её вручную — это полноценный рабочий режим без подключения платёжного шлюза.

---

## Шаг 5. Запустите бота

Откройте командную строку в папке с проектом (там, где лежит файл `docker-compose.yml`) и выполните:

```
docker compose up --build
```

Docker скачает все необходимые компоненты и запустит бота. Первый запуск займёт 3–5 минут. Когда в логах появится строка `Application startup complete`, бот запущен.

> Оставьте это окно командной строки открытым — оно запускает бота.

---

## Шаг 6. Запустите ngrok и установите webhook

**В отдельном окне командной строки** (не закрывайте первое!) выполните:

```
ngrok http 80
```

Вы увидите строку вида:
```
Forwarding   https://abc123.ngrok-free.app -> http://localhost:80
```

Скопируйте HTTPS-адрес (`https://abc123.ngrok-free.app`).

Теперь:
1. Откройте файл `.env`.
2. Найдите строку `WEBHOOK_BASE_URL=`.
3. Вставьте скопированный адрес: `WEBHOOK_BASE_URL=https://abc123.ngrok-free.app`.
4. Сохраните файл.

Перезапустите контейнер бота, чтобы применить новый адрес:

```
docker compose up -d --force-recreate bot
```

> Адрес ngrok меняется каждый раз при перезапуске ngrok. После перезапуска повторите этот шаг.

---

## Шаг 7. Проверьте, что бот работает

В командной строке выполните:

```
curl http://localhost/health
```

Если видите `{"status":"ok"}` — всё работает.

Затем откройте Telegram, найдите вашего бота и напишите `/start`. Бот должен ответить.

---

## Шаг 8. Настройте бизнес-параметры через Telegram

Напишите вашему боту `/start`. Так как вы указали свой Telegram ID в `OWNER_TELEGRAM_ID`, бот распознает вас как владельца и предложит пройти мастер настройки.

Параметры, которые можно настроить:

| Параметр | Что это | Пример |
|----------|---------|--------|
| `service_name` | Название вашего сервиса | `Агентство копирайтинга "Текст"` |
| `welcome_text` | Приветственное сообщение для новых клиентов | `Привет! Оставьте заявку, и мы выполним её в срок.` |
| `support_contact` | Контакт поддержки | `@your_support_username` |
| `payment_requisites` | Реквизиты для ручной оплаты | `Карта Сбербанк: 4276 0000 0000 0000` |
| `max_active_orders` | Максимум активных заявок от одного клиента одновременно | `3` |
| `auction_timeout_minutes` | Сколько минут операторы могут подавать ставки | `30` |
| `operator_payout_percent` | Процент от стоимости заявки, который получает оператор | `70` |

Все эти параметры можно изменить в любой момент прямо в Telegram, не перезапуская бота.

## Типичные проблемы и решения

### Бот не отвечает в Telegram

**Причина:** webhook не установлен или ngrok не запущен.

**Решение:**
1. Убедитесь, что ngrok запущен (`ngrok http 80`) и показывает HTTPS-адрес.
2. Проверьте, что этот адрес скопирован в `WEBHOOK_BASE_URL` в файле `.env`.
3. Перезапустите контейнер: `docker compose up -d --force-recreate bot`.
4. Проверьте: `curl http://localhost/health` — должен вернуть `{"status":"ok"}`.

### Порт 80 занят

**Сообщение об ошибке:** `bind: address already in use` или `port is already allocated`.

**Причина:** на компьютере уже запущен другой веб-сервер (Skype, IIS, Apache или другой Docker-контейнер).

**Решение:**
- Остановите конкурирующую программу.
- Или откройте `docker-compose.yml`, найдите строку `"80:80"` в разделе nginx и замените на `"8080:80"`. Тогда используйте `ngrok http 8080`.

### Неверный токен бота

**Сообщение об ошибке:** `401 Unauthorized` в логах Docker.

**Решение:** проверьте `BOT_TOKEN` в файле `.env` — скопируйте токен заново из сообщения BotFather без пробелов и переносов строк.

### Не работает webhook

**Сообщение об ошибке:** `Failed to set webhook` в логах.

**Возможные причины:**
- `WEBHOOK_BASE_URL` содержит `http://` вместо `https://` — Telegram принимает только HTTPS.
- ngrok не авторизован — выполните команду авторизации из личного кабинета ngrok.
- `WEBHOOK_SECRET` содержит спецсимволы — используйте только буквы и цифры.

### Неверный OPERATOR_GROUP_ID

**Симптом:** операторы не видят новые заявки.

**Решение:**
1. Убедитесь, что ID начинается с `-100`, например `-1001234567890`.
2. Убедитесь, что бот добавлен в группу и назначен администратором.
3. Пересоздайте группу, если ID не удаётся получить: добавьте @RawDataBot, отправьте любое сообщение — он покажет `chat.id`.

### Ошибка подключения к базе данных

**Сообщение:** `password authentication failed` или `could not connect to server`.

**Решение:** убедитесь, что пароль в `POSTGRES_PASSWORD` совпадает с паролем внутри строки `DATABASE_URL`. Оба значения должны быть одинаковыми.

## После перезапуска компьютера

При перезапуске компьютера нужно:

1. Запустить Docker Desktop (откройте приложение).
2. В командной строке в папке проекта: `docker compose up -d`.
3. В новом окне: `ngrok http 80`.
4. Скопировать новый HTTPS-адрес ngrok в `.env` → `WEBHOOK_BASE_URL`.
5. Перезапустить контейнер бота: `docker compose up -d --force-recreate bot`.

> Совет: если вы планируете использовать бота постоянно, рассмотрите хостинг на VPS-сервере — тогда ngrok не понадобится, а адрес будет постоянным. Обратитесь к разработчику за помощью с переносом на сервер: инструкция по развёртыванию на сервере находится в файле [DEPLOYMENT.md](DEPLOYMENT.md).
