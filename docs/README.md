# Техническая документация

Этот каталог предназначен для технических материалов проекта: схем, заметок по архитектуре, описаний сценариев и дополнительных инструкций по сопровождению Telegram-бота.

Основные инструкции находятся в корне репозитория:

- [README.md](../README.md) — обзор проекта и быстрый запуск;
- [QUICKSTART.md](../QUICKSTART.md) — пошаговый локальный запуск;
- [DEPLOYMENT.md](../DEPLOYMENT.md) — эксплуатация и развёртывание;
- [BUSINESS_OWNER_GUIDE.md](../BUSINESS_OWNER_GUIDE.md) — инструкция для владельца бизнеса.

Файлы, не относящиеся к запуску и сопровождению бота, в публичный репозиторий не включаются.
